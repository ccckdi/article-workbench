# 文章阅读历史数据

本目录提供合成历史数据，用于作者阅读概览、文章表现比较与读者画像。包含两位作者的 8 篇文章及两个批次的阅读记录；不含真实个人信息。可通过初始化、脚本或系统导入接入，不要求独立的导入管理页面。

## 文件与范围

| 文件 | 内容 |
| --- | --- |
| articles.csv | 文章快照、所属作者和历史发布信息 |
| reading-events-01.csv、reading-events-02.csv | 阅读访问与阅读结束上报，批次可能重叠，无先后覆盖含义 |
| manifest.json | 数据范围、原始行数与 SHA-256 |

UTF-8 编码，CSV 第一行为字段名；正文包含换行，应使用 CSV 解析器。历史观察范围为北京时间 2026-08-01 00:00（包含）至 2026-08-15 00:00（不包含），导出截止为 2026-08-17 00:00。正常时间字段含时区偏移，发生时间与收到时间可能不同。

原始记录可能重复、缺失、冲突或无效，也可能来自自动访问。处理规则由候选人选择，确保页面统计与实际数据一致并能解释差异。manifest 行数不是有效访问量。

历史文章的 author_id 对应演示账号 user-alice 和 user-bob，各有 4 篇。它是作者访问范围的依据，不能仅在页面中隐藏其他作者的数据。published_version 为历史来源标识，不是应用内的批准记录。历史快照可以用于分析；用于新公开演示的文章应按本题审核发布。

## articles.csv

| 字段 | 含义 |
| --- | --- |
| article_id | 历史文章稳定标识 |
| author_id | 所属作者，关联演示账号 |
| title、excerpt、body | 标题、摘要和正文快照 |
| topic | 文章主题 |
| published_at | 该快照版本的历史发布时间 |
| published_version | 历史内容版本标识 |

## reading-events-*.csv

| 字段 | 含义 |
| --- | --- |
| event_id | 上报事件标识；重传应保持不变，不同批次可能重复或存在冲突 |
| session_id | 一次文章访问会话，可关联 page_view 和 read_end；可能缺失 |
| anonymous_id | 合成浏览器标识，可能为空；不是实名用户或真实人数 |
| article_id、content_version | 访问的文章和内容版本 |
| event_type | page_view 为页面访问，read_end 为阅读结束上报；可能有未约定值 |
| occurred_at、received_at | 事件发生时间和服务端接收时间 |
| channel | 来源渠道：search、home、campaign、direct；可能缺失 |
| device | desktop 或 mobile |
| region | 省级地区或未知，全部为合成值，不包含详细位置 |
| client_agent | browser、crawler 或 unknown，作为判断访问来源的线索 |
| duration_seconds | read_end 上报的页面停留秒数；page_view 通常为空 |
| scroll_percent | read_end 上报的最大滚动百分比，约定 0–100 |

一次访问可能没有 read_end，不能把结束事件再当一次新访问。停留时长和滚动深度可以反映阅读行为，但不保证读者读完或理解了内容。

相同浏览器可能重复访问，同一人也可能使用多个浏览器。可以据观察期内的记录定义回访；资料不包含全站完整的首次访问历史，不应把“本期首次出现”当作确定的终身新读者。访客数及回访口径需在交付说明中说明。

来源、设备和地区用于汇总画像。未知值应如实保留，不要求推断年龄、性别、职业或兴趣标签。新产生的访问可以采集浏览器能可靠提供的信息；地区无法可靠获得时显示未知，无需接入付费定位服务。
